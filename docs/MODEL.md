# 生态模型与参数口径（ABM–02）

参数页 `/settings.html` 展示47项参数的默认值、合法范围、单位、过程公式与应用时机。入口保留在观测站顶栏。全部系数由 `shared/environment.ts` 与 `shared/model.ts` 定义，模拟和响应预览共用植物响应函数。

## 模型定位与单位

这是具有空间行为的个体生态模型，用于探索资源限制、捕食、生命史与遗传性状之间的反馈。默认系数为演示参数，未使用真实野兔、赤狐或流域数据进行估计，不能把模拟结果直接解释为现实数量预测。

| 量 | 单位/定义 |
| --- | --- |
| 时间 | 模拟秒；固定生物步长0.2秒。墙钟倍速不改变各项过程系数 |
| 空间 | 相对格；没有自动映射到米、平方米或领地面积 |
| 植被 | VU，相对植被单位；单格范围0–100，内部量化分辨率0.01 VU |
| 动物能量 | EU，模型体内能量单位；兔容量130 EU，狐145 EU |
| 土壤水分/养分、水位、体内水分 | 0–100相对指数；“点/s”表示指数变化速度，并非百分比增长率 |
| 碎屑 | 土壤单元内的相对碎屑指数，不是实际有机碳质量 |
| 遗传性状 | 无量纲；单一性状同时影响移动和维持消耗，范围0.7–1.4 |

水、植被、碎屑和能量使用不同的抽象单位。模型含截断、最低捕食收益、背景补水、外部降雨与饱和上限，**不是可闭合的质量/能量守恒预算**。不应把此处同化系数误认为经过实测标定的营养级传递效率。

## 参数分类

自然演变单独使用三个布尔开关（天气、自然山火、边界迁入），不计入47项连续系数。天气是季节加权的可复现程序过程，非现实气象预报。每720步开启一个窗口，180步后开始、持续300–449步；类型的降雨/温度/光照修正见 `shared/nature.ts`。修正同时进入动物生理与分区水土积分，基础系数保持原值。切换天气前先结算旧区间，避免将新开关追溯应用到休眠分区。

火险 = clamp((45−平均水分)/40) × clamp((实际温度−15)/25) × min(1,平均植被/35)，各clamp范围0–1。每100步以 `0.22 × 火险` 的机会尝试点火，最多检查32个位置，要求当地水分<40、植被>25且为陆地；火场采用原有局部山火机制，不模拟蔓延、风场或灭火。显示指数为火险×100，不能解释成发生概率。

迁入每600步尝试（相位450），春夏秋冬尝试机会分别1、0.8、0.65、0.35；类型兔/狐机会0.78/0.22，群体大小4–8/2。落点要求边界内1–3格的陆地、水分≥25和植被≥20；不符合则本次无迁入。个体随后遵循既有自主行为与能量规则，性状来自现有初始分布；不计作出生，不代表已实现完整的外部种群守恒或定向季节迁徙。

| 类别 | 数量 | 内容 |
| --- | --- | --- |
| 气候强迫 | 5 | 基温、降雨倍率、日照倍率、季节振幅、昼夜温差 |
| 水文与土壤 | 5 | 入渗、基础蒸发、热蒸发、水体补给、岸边补水 |
| 初级生产 | 8 | 肥力倍率、生产率、最适温度、耐受宽度、水肥饱和阈值、水肥消耗 |
| 分解与循环 | 5 | 分解常数、回收系数、Q10、独立热适宜中心与耐受宽度 |
| 摄食与生理 | 12 | 营养、代谢倍率、两物种速度、感知、失水、饮水、摄草、同化、两物种维持消耗 |
| 生命史与演化 | 12 | 寿命倍率、繁殖倍率、变异、幼体代谢、两物种成熟年龄/孕期/寿命、配对距离 |

数值输入接受范围内的任意有限小数，服务端不按UI步长取整。详细参数页使用温区端点、秒/分钟、百分比、分钟速率、参考半衰期等针对性编辑器；所有换算最终形成同一单位的参数草稿，温区端点会同时更新中心与宽度。自定义微调量控制±按钮与键盘步进，不限制直接输入精度；相对微调对零值不产生变化，可切换绝对微调或直接输入。服务端整批校验，任一参数无效则整批不应用。生命史参数允许构造极端条件，例如成熟年龄超过有效寿命，此时可能无法自然繁殖。界面不以“正常生态”强制限制实验。

显示采用独立的简短格式：常用数值保留1–2位小数，小于1的系数按数量级保留必要位数，更小的系数使用简短科学记数法；时间码显示到0.01秒。完整精度只在编辑、悬停提示、JSON与CSV中保留。显示字符串不会反写模型；精细模式只影响对应参数的手势/步进，不改写原始存储精度或其他通道。

## 主要过程

### 气候与日历

一天120模拟秒，一季6天，一年24天。季节改变光周期、基温偏移、降雨和受孕尝试概率；昼夜振幅控制日内温差。

```text
实际温度 = 基温 + 季节温度偏移 × 季节振幅 + 昼夜振幅 × cos(时相)
实际降雨 = 基础降雨 × max(0, 1 + (季节雨量系数 − 1) × 季节振幅)
实际光照 = 昼夜光照因子 × 日照倍率
```

季节振幅0关闭温度、雨量和繁殖的季节修正，但四季名称和季节光周期仍变化。该参数并非关闭日历或光周期的总开关。

### 初级生产与水肥约束

```text
fT = max(0, 1 − |温度 − 植物最适温度| / 植物耐受宽度)
fW = min(1, 土壤水分 / 水分饱和阈值)
fN = min(1, 土壤养分 / 养分饱和阈值)
潜在增长率 = 生产率 × 肥力倍率 × 实际光照 × fT × fW × fN
```

这里使用乘法共同限制与分段线性饱和响应；饱和阈值不是Monod半饱和常数。实际增长还受每格100 VU上限、土壤可用水肥量和0.01 VU分辨率约束。8×8土壤单元内新增的VU逐项扣除耗水、耗肥系数；计算增长上限时保守地按64格预算。

响应图直接调用模拟中的 `growthPotential`。两条曲线分别扫描温度和水分，固定非扫描的水分与养分为100，日照取草稿/当前参数，水分曲线使用对应基温，不叠加季节、时相与实际资源消耗。它是条件响应预览，并非修改后的未来种群预测或经验敏感性置信区间。

```text
蒸发 = 基础蒸发 + max(温度, 0) × 热蒸发系数 × max(实际光照, 0.1)
土壤水分变化 = 入渗率 × 实际降雨 − 蒸发 + 岸边补水 − 植物耗水
水位变化 = 补给率 × 实际降雨 + 0.025 − 蒸发 − 饮用扣减
```

各指数截断至合法范围。岸边补水仅在所在土壤单元有水体且水位大于20时启用；水位低于10时不能饮用。未模拟流域径流、地下水位或真实水力连通。

### 分解与养分循环

```text
分解热适宜度 = max(0, 1 − |温度 − 分解热适宜中心| / 分解耐受宽度)
分解水分因子 = min(1, 土壤水分 / 50)
k有效 = 分解常数 × 热适宜度 × 水分因子 × Q10^((温度 − 20)/10)
本区间分解量 = 碎屑存量 × (1 − exp(−k有效 × 区间秒数))
养分回补 = 分解量 × 回收系数
```

Q10的参考温度固定为20°C。热适宜度与Q10的乘积可能使实际峰值偏离热适宜中心；这是近似过程函数，不是单一酶动力学定律。默认Q10=1保留原模型温度尺度，可用1–3探索温度敏感性。植物最适温度不会改变分解适宜中心。

### 摄食、代谢和行为

草食摄入量受脚下可用VU与最大摄草率约束；乘草食同化系数和植物营养倍率成为能量收益。捕食者通过空间感知、追逐和接触捕获获取猎物的剩余能量，采用最低8 EU奖励和145 EU容量上限；未拟合Holling功能反应。

两物种维持消耗分别用EU/s指定，再乘基础代谢、基因、相对20°C的温度压力、活动和幼体修正。兔与狐为恒温动物，因此没有把环境温度直接作为体温代入统一Q10；此模型也未建立详细的热调节预算。

饥饿与水分不足驱动觅食、寻水。兔优先躲避捕食者，缺水时寻水，满足条件时休息。密集区空间邻居按桶轮换采样，局部绕障代替全图最短路径，可能忽略最近个体或受地形困住。

### 生命史

成熟的雌雄个体在有效感知和配对距离内、能量/水分与冷却条件满足时才可能受孕。0.2秒步长的尝试概率为 `0.025 × 对应物种繁殖倍率 × 季节因子`，不是整群瞬时出生率。现有孕期倒计时不会因修改新妊娠时长而被重写；低能量可能终止妊娠。

寿命倍率乘对应物种基准寿命得到确定性年龄上限。成熟阈值修改后立即用于行为与截面分类；降低寿命可能导致现存个体在下一步死亡。每次成功妊娠一只幼体，短期跟随与哺育。幼体速度固定为成体0.65倍，15模拟秒内可受母体哺育。

后代性状为双亲均值加 `Uniform(−0.05,0.05) × 变异倍率`，截断至0.7–1.4。此单性状模型不含性别连锁、隐显性、多位点遗传或近交系数。

## 分析图与采样定义

服务器通常每5模拟秒采样，保留最近240点；参数应用、干预与扩图可能增加采样，同一时刻替换而不重复。旧存档中缺失的新字段保留为空缺，不回填虚构历史。重启恢复已保存的历史。当前结构与卡片来自全世界当前状态，不取浏览器视野内的样本。

| 图表 | 定义与解释 |
| --- | --- |
| 种群动态 | 全世界兔、狐个体数，同一数量轴；可切线性/对数 |
| 资源限制 | 全部土壤单元的水分/养分算术均值（含水域、岩地单元）；植被为可栖息陆地格平均VU，不是盖度百分比 |
| 出生/死亡通量 | 相邻累计计数差 ÷ 模拟分钟差；出生只含自然出生，死亡含山火干预；不是每个体的发生率 |
| 相轨迹 | 横轴兔数，纵轴狐数，按时间连接；轨迹亮度表示先后，不等于因果识别 |
| 群体生理 | 全体个体平均体内水分，以及每个体先按所属物种容量归一化后再求平均的能量百分比；没有动物时留空 |
| 结构与性状 | 当前幼体/成体、雌性和孕育数；性状均值和总体标准差σ，不是生物多样性指数 |

曲线按真实模拟时间定位，时间窗以模拟秒筛选，不以条目数冒充时间。CSV导出全部当前保留的采样，缺失字段和空种群生理均值留空；仍可通过 `grazers+hunters` 区分灭绝与历史缺测。图表默认显示240点窗口，不能替代长期实验记录；需要更长记录时应定期导出。

CSV中 `plants` 沿用观测站历史口径，为 `round(全图VU总量/100)`，不是全图原始VU；`plantMean` 才是每个可栖息格平均VU。`meanEnergy` 单位EU，`energyReserve` 为归一化百分比，`geneSD` 使用总体标准差。`tick` 每5步等于1模拟秒，另提供 `simulation_seconds` 列方便计算。旧的 `diversity` 字段实为性状均值×100的兼容字段，实验室不把它作为多样性指标展示或导出。

服务器植物分区更新，每步处理上限64个动物活跃区和2个轮巡区，休眠区域用最多8点气候积分补算。土壤均值和植被总量反映分区最近更新状态，存在延迟和近似积分误差。改参前会先按旧参数结算区间。人工扩图会改变陆地总面积、总体资源与均值，需要结合事件解释。

## 可重复实验建议

1. 同时保存世界SQLite备份与当前参数JSON。参数JSON只保存系数、来源、导出时刻与世界尺寸，不包含完整个体状态、随机数或管理口令。
2. 先运行基线，再从相同世界备份开始、仅改变一个过程参数。比较方案时保留同样的起始种群和随机种子。
3. 等待足够模拟时间，再比较资源、种群和出生/死亡通量。干预、扩图与参数变更都会产生混杂，应记录操作。
4. 用不同随机种子重复实验，计算多次运行的均值与离散程度。页面未自动执行重复试验，单条随机轨迹不提供统计置信度。
5. 对真实生态系统应用前，需要定义空间/时间/质量单位映射，用观测数据标定参数并在独立数据上验证。
